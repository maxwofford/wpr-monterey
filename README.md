# monterey

<img src="https://cdn.hackclub.com/01a0b1f5-54e1-7891-955a-70120c15e031/monterey.png" width="800" alt="monterey, seed 6">

a shader for [wpr](https://github.com/maxwofford/wpr), the wallpaper manager.

```sh
brew tap maxwofford/wpr && brew install wpr   # if you don't have wpr yet
wpr install maxwofford/monterey
wpr gen monterey                              # a new one, set as your wallpaper
wpr enable monterey                           # add it to your rotation
```
